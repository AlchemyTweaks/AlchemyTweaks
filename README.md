## About me

Hey, I'm Alchemy. I work on Windows performance tuning, mostly for gaming and low latency setups.

The way I do it is pretty simple. I sort every tweak by how well it's proven. Some come straight from official docs (Microsoft, NVIDIA, Intel, AMD). Others I test myself with real benchmarks and frame timing before I trust them. If I can't actually measure a difference, I don't post it.

Everything I make is in one place: [linktr.ee/Alchemyweaks](https://linktr.ee/Alchemyweaks)
