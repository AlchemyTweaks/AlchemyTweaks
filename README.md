## &nbsp;🧪&nbsp; About

I build and validate **Windows performance optimizations** for gaming and low-latency systems. Every configuration I publish is sorted by **evidence level** — from settings backed by official vendor documentation, to tweaks empirically benchmarked with frame-level telemetry. Nothing ships without measurement.

- 🎯 **Focus** — Frame-time stability, input latency, and reproducible FPS gains on Windows 10 / 11
- 🔬 **Method** — Controlled A/B captures, DPC/ISR &amp; ETW trace analysis, statistical validation of every delta
- 📚 **Principle** — *No claim without a benchmark. No tweak without evidence.*
- 🌐 **Everything in one place** — [linktr.ee/Alchemyweaks](https://linktr.ee/Alchemyweaks)
